# Where Can Nature Survive Climate Change?

Интерактивный геопортал из двух карт для картографического челленджа: где к 2050 году сохранятся климатические убежища (рефугиумы) для природы и какие территории с высоким биоразнообразием с ними совпадают.

Слева панель с описанием, переключателем карт и сценариев, легендой и рейтингами. Справа карта: по клику на суше открывается карточка со значениями всех показателей в этой точке. Интерфейс на английском.

| | Карта | Вопрос |
|---|---|---|
| **MAP 01** | **Where Will Nature Find Refuge?** — Mapping Potential Climate Refugia by 2050 | Где сохранятся относительно благоприятные климатические условия для природных экосистем? |
| **MAP 02** | **Which Species Will Have a Safe Haven?** — Biodiversity and Climate Refugia | Какие территории с высоким биоразнообразием совпадают с потенциальными климатическими убежищами? |

## Как опубликовать на GitHub Pages

1. Создайте репозиторий и загрузите в его корень всё содержимое папки (`index.html`, `assets/`, `data/`, `scripts/`, `.nojekyll`).
2. Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**, выберите ветку `main` и папку `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<username>.github.io/<repo>/`.

Сборщик не нужен: страница статическая, Leaflet лежит в `assets/vendor/`. Подложка и подписи рисуются из собственных файлов Natural Earth, поэтому внешних тайловых сервисов, ключей и лимитов нет. Из интернета подгружаются только бесплатные шрифты Google Fonts, без них страница тоже работает.

Локальный просмотр (из-за `fetch` нужен сервер, двойной клик по файлу не подойдёт):

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

Состояние карты записывается в адрес, поэтому ссылкой можно поделиться: `#m1/ssp585/index`, `#m2/ssp245/biv`. Клавиши `1` и `2` переключают карты.

## Что на картах

### MAP 01 — климатические рефугиумы

Переключатель сценариев: **SSP1-2.6 / SSP2-4.5 / SSP5-8.5**, горизонт 2041–2060 относительно 1995–2014.

| Слой | Что показывает |
|---|---|
| **Climate refugia index** | Интегральный индекс в 5 классах, от *Highly exposed* до *Strong refugium* |
| **Projected warming** | Прирост среднегодовой температуры суши (медиана ансамбля CMIP6) |
| **Climate velocity** | Скорость смещения климатических зон по местности, км/год (Loarie et al., 2009) |
| **Topographic diversity** | Перепад высот в окне ~55 км: склоны и долины, где возможны микрорефугиумы |

На панели: ключевые цифры по трём сценариям и рейтинг регионов IPCC AR6, где рефугиумов больше всего и меньше всего.

### MAP 02 — биоразнообразие × рефугиумы

| Слой | Что показывает |
|---|---|
| **Safe havens vs. biodiversity at risk** | Биварианная карта 3×3: богатство видов × индекс рефугиумов |
| **Vertebrate species richness** | Число видов амфибий, птиц, млекопитающих и рептилий в ячейке 0,5° |
| **Threatened species richness** | Число угрожаемых видов (амфибии, птицы, млекопитающие) |

Поверх карты контуры **35 горячих точек биоразнообразия** Conservation International. Таблица на панели показывает долю рефугиумов и уязвимых территорий в каждой горячей точке. По клику на строку карта перелетает к выбранной точке.

**Как читать биварианную легенду:**
- ⬜ **Safe haven** — много видов и устойчивый климат;
- 🟪 **Biodiversity at risk** — много видов, но высокая климатическая уязвимость;
- 🟩 **Refuge, fewer species** — стабильные территории, куда виды могут мигрировать.

## Основные результаты

| | SSP1-2.6 | SSP2-4.5 | SSP5-8.5 |
|---|---|---|---|
| Потепление суши к 2041–2060, °C (медиана CMIP6) | +1,3 | +1,6 | +2,3 |
| Доля суши (без ледников) с умеренным или сильным потенциалом рефугиума | 58 % | 39 % | 19 % |
| Доля суши с сильным потенциалом рефугиума | 36 % | 18 % | 3 % |
| Доля самых богатых видами земель, которые остаются «safe haven» | 53 % | 32 % | 13 % |
| Доля самых богатых видами земель с высокой уязвимостью | 16 % | 35 % | 60 % |

Классы заданы фиксированными порогами (квинтили при SSP2-4.5), поэтому сценарии сравниваются напрямую. Абсолютные доли зависят от выбранных порогов, поэтому важнее смотреть, как они меняются от сценария к сценарию.

- **Главные рефугиумы — горы**: Анды, Гималаи, горы Центральной Азии и Юго-Западного Китая, Скалистые горы, Эфиопское нагорье, восток Австралии, Новая Зеландия. Рельеф создаёт резкие температурные градиенты: чтобы сохранить привычный климат, виду достаточно подняться выше по склону.
- **Самые уязвимые — равнинные тропики** (бассейны Конго и Амазонки, Сахель) и **плоские бореальные равнины**. В тропиках естественная изменчивость температуры мала, поэтому даже умеренное потепление быстро выводит климат за пределы привычного.
- Среди горячих точек при SSP2-4.5 устойчивее всех горные: Гималаи, Тропические Анды, леса Восточной Австралии. Сильнее всего под угрозой Прибрежные леса Восточной Африки, Гвинейские леса Западной Африки, Карибские острова и Серрадо.

## Методика

**Базовый климат.** Климатология температуры воздуха на высоте 2 м по ERA-Interim (ECMWF, ~0,7°) уменьшена до сетки 10′ (~18 км) по рельефу ETOPO5 с вертикальным градиентом 6,5 °C/км.

**Проекции.** Медиана мультимодельного ансамбля CMIP6 (32–34 модели) по изменению температуры суши, 2041–2060 против 1995–2014, для 46 сухопутных регионов IPCC AR6 (IPCC WGI Atlas). Чтобы убрать ступеньки на границах регионов, поле сглажено гауссовым фильтром (σ = 3°).

**Показатели:**
1. **Скорость климата** = (ΔT / 45 лет) / |∇T|, км/год. Пространственный градиент считается по окну 3×3 (Loarie et al., 2009).
2. **Климатическая новизна** = ΔT / σ, где σ — межгодовая изменчивость (стандартное отклонение остатков после удаления тренда, 1965–2014, медиана по моделям). Это отношение сигнал/шум, как в работах о времени появления сигнала (Hawkins & Sutton, 2012).
3. **Топографическое разнообразие** = перепад высот ETOPO5 в окне ~55 км.

**Индекс рефугиумов** = 0,5 × (низкая скорость) + 0,3 × (низкая новизна) + 0,2 × (рельеф). Каждый показатель переводится в перцентиль 0–1 по распределению SSP2-4.5, и эта же шкала применяется к остальным сценариям.

**Биоразнообразие.** Ареалы видов растеризованы на сетку 0,5° пакетом rasterSp: амфибии и млекопитающие — IUCN Red List, птицы — BirdLife International, рептилии — GARD (Roll et al., 2017). Биварианные классы строятся по терцилям богатства видов и терцилям индекса (пороги SSP2-4.5).

**Исключено:** постоянные ледники (Natural Earth) и всё южнее 60° ю. ш.

### Ограничения

- Это индикативный **скрининговый индекс**, а не прогноз для конкретных видов.
- Сетка CMIP6 доступна в виде региональных средних, поэтому крупномасштабное потепление внутри региона одинаково. Пространственную детализацию дают только базовый климат и рельеф.
- Учитывается только температура. Осадки, засухи, пожары и землепользование в индекс не входят.
- Скорость климата зависит от разрешения: на более мелкой сетке она ниже. Сравнивайте территории между собой, а не абсолютные км/год.
- Ареалы из экспертных карт завышают присутствие видов на мелком масштабе.

## Структура репозитория

```
index.html                  страница геопортала
assets/css/style.css        стили
assets/js/app.js            логика: слои, легенды, рейтинги, клик-карточка
assets/vendor/leaflet/      Leaflet 1.9.4 (BSD-2)
data/layers/*.png           растровые слои в Web Mercator (−60…85°)
data/grid.json              значения в ячейках 0,5° для карточки по клику
data/stats.json             цифры, пороги, палитры, статистика горячих точек
data/hotspots.geojson       горячие точки (упрощённые контуры)
data/countries.geojson      подложка (Natural Earth 1:110m)
data/labels.json            подписи стран и городов (Natural Earth)
scripts/fetch_data.sh       скачивание исходных данных (~60 МБ, всё с GitHub)
scripts/prep_richness.py    ареалы → сетки богатства видов
scripts/build_data.py       расчёт всех слоёв и статистики
```

### Пересборка данных

```bash
pip install -r scripts/requirements.txt
bash scripts/fetch_data.sh raw
python scripts/prep_richness.py raw
python scripts/build_data.py raw data
```

Расчёт занимает около 20 секунд. Веса индекса, пороги, палитры и диапазоны задаются в начале соответствующих блоков `build_data.py`.
